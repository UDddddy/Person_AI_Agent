# docs/daily・每日动态提示词记录

这是本项目的学习 / 对话**动态存档目录**：每天结束时，自动把当天的询问记录整理成一份带时间戳的提示词文档，既方便回顾，也可作为 "动态提示词" 素材（跨天记住你学到哪）。

## 触发方式

当你决定休息 / 结束今天的学习时，**直接说 "休息"**（或 "今天到这"、"收工"），我就会：



1. 汇总今天这个会话里你的**所有询问记录**（你问的问题 / 提出的需求）

2. 生成一份 `YYYY-MM-DD_学习记录.md`（标注日期、时间、学习主题）

3. 存进本目录并交付给你

## 文件命名与结构



```
docs/daily/

├── README.md                      ← 本说明

├── 2026-09-01\_学习记录.md          ← 每天一份，按日期递增

└── ...
```

每份记录的标准结构：



```
\# 学习记录 · YYYY-MM-DD（周X）

\- 记录时间：HH:MM - HH:MM

\- 今日主题：一句话概括

\## 今日询问记录

1\. 问题/需求 1

2\. 问题/需求 2

...

\## 今日产出

\- 产出的文件 / 完成的功能 / 达成的结论

\## 今日关键结论

\- 今天想明白的重要概念

\## 明日计划

\- 下一步要做什么
```

## 这份文件的两重用途



1. **学习回顾**：打开任何一天，就能看到 "那天我困惑过什么、最后怎么解决的"。

2. **动态提示词素材**：如果以后要让项目 Agent 跨天记住你的学习进度，这份文件就是天然的 "动态提示词"—— 把最近几天的记录拼进系统提示词，Agent 就知道你学到哪、问过什么。
