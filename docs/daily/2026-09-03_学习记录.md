## 今日关键结论

1. **循环导入**：`registry → run_command → registry` 循环时，Python 拿到半初始化模块 → ImportError。工具类只依赖基类，注册交给注册表（单向依赖）。
2. **pydantic v2 硬规则**：子类覆盖基类带注解字段时，覆盖也必须带类型注解（`name: str = ...`），否则 `PydanticUserError`。
3. **interrupt 是"暂停-恢复"握手，不是异常**：实测 `invoke` 遇中断**返回**带 `__interrupt__` 键的结果（不是抛异常）；恢复用 `Command(resume=决策)`，节点从头重跑，interrupt 返回 resume 值。
4. **两段式驱动**：`while "__interrupt__" in result:` → 取 `payload` → 人类决策 → `Command(resume=...)` 恢复，**同一 thread_id**。
5. **外部驱动只喂决策，图内节点处理决策**：拒绝也要恢复图（生成"被拒"ToolMessage 让 LLM 看到），驱动层不越权 return。
6. **SqliteSaver.from_conn_string 返回上下文管理器**：必须 `with ... as cp:` 才拿到真 saver。
7. **图结构与节点实现解耦**：基础 / HITL / SSE 三图拓扑完全相同（start→agent→(条件)tools/end），差异只在节点内部——这正是"LangGraph 作承载底盘"的原因。
8. **git 代理要点**：系统代理开关变化 git 不感知，需手动配（`git config http.proxy ...`）/清（`--unset`）；诊断顺序：先测直连、再测代理端口。
